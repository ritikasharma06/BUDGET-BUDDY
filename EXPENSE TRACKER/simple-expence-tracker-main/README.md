# Budget Buddy — Smart Personal Finance & Expense Tracker

> **AI-Powered Personal Finance & Expense Intelligence Platform**

Budget Buddy is a comprehensive FinTech web application built with modern vanilla web technologies (HTML5, CSS3 Glassmorphism, JavaScript ES6+) and Node.js. It features a complete 20-module financial suite including real-time overview analytics, transaction ledger, multi-wallet accounts, smart budgets, AI financial advisor, health score calculation, subscription management, goal tracking, and report generation (PDF, Excel, CSV).

## Key Features

- **Strict Authentication & Route Isolation**: Independent login page view with secure session management and persistent state.
- **Financial Dashboard**: Real-time balance calculations, savings rate, and financial health score.
- **Transactions & Ledger**: Real-time filtering, categorization, multi-currency support, and tag system.
- **Smart Budgets & Multi-Wallets**: Track spending per category and manage bank, cash, and digital wallet accounts.
- **AI Financial Assistant**: Integrated natural language query assistant for financial advisory.
- **Export & Backup**: One-click export to PDF, Excel, CSV, and full JSON data backups.
- **Responsive Design**: Designed with glassmorphism UI optimized for desktop, tablet, and mobile displays.
